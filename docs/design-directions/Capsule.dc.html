1Three directions for the capsule
What's shared across all three

San Francisco throughout — SF Pro for everything you read, SF Mono for every piece of metadata (dates, lot numbers, counts, field labels). That split is the whole typographic system: prose is warm, data is archival. Hairline rules instead of boxes. Every object is a die-cut cutout with a white sticker edge and a real shadow, never a rectangle in a card.

Every direction carries a Still have it / Only here now state, since some of these replace the physical object and some don't. Same five fields everywhere: who, when, where from, occasion, and the story.

What differs
Ledger — time is the spine. Stickers sit still and behave.
Board — space is the spine. You arrange them by hand.
Cabinet — the object is the spine. One at a time, lit.
1aThe Ledger — chronological, museum-quiet. Cutouts float on paper; a permanent inspector holds the story.
